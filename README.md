# CodSoft Data Analytics Internship

## 📌 Overview

This repository contains the tasks completed as part of my **CodSoft Data Analytics Internship**.

The projects focus on data cleaning, data analysis, and data visualization using Python.

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook / VS Code
- GitHub

## 📂 Tasks Completed

### Task 1 – Data Cleaning and Analysis

Performed basic data cleaning and analysis using the Titanic dataset.

**Tools:** Python, Pandas

### Task 2 – Exploratory Data Analysis

Analyzed the Titanic dataset and generated descriptive statistics to understand the data.

**Tools:** Python, Pandas

### Task 3 – Data Visualization

Created different visualizations to understand passenger survival patterns, including:

- Titanic Survival Count
- Survival by Gender
- Passengers by Class
- Age Distribution
- Fare vs Age

**Tools:** Python, Pandas, Matplotlib, Seaborn

### Task 4 – Customer Data Analysis

Worked with customer-related data using `customers.csv` and performed data analysis using Python.

**Tools:** Python, Pandas, Matplotlib, Seaborn
